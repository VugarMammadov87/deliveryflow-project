Financial Calculations & Unit Economics Formulas

During the Silver and Gold transformation stages, Apache Spark computes critical financial efficiency and risk indicators:

±
Cost Variance
cost_variance = actual_total_cost - planned_cost

cost_variance_pct = (actual_total_cost - planned_cost) / planned_cost

Measures budgetary discipline per route and warehouse corridor.
Budgetary Tracking Row-level & Aggregated
÷
Unit Transit Costs
cost_per_km = actual_total_cost / actual_distance_km

cost_per_delivery = actual_total_cost / delivery_count

Evaluates transport efficiency independent of total route scale.
Unit Economics Efficiency Metric
⛽
Fuel Cost Share
fuel_cost_pct = fuel_cost / actual_total_cost

Tracks volatility exposure to diesel/gasoline price swings across vehicle types and driving behaviors.
Expense Composition Fuel Share
⚠
Cost & Delay Risk Score
cost_delay_risk_score = cost_variance_pct + delay_rate

Combines batch cost overruns with operational delivery delay rates to identify high-risk logistics corridors.
Operational Risk Index Hybrid View Metric

ClickHouse Hybrid Analytical View

To keep Superset connected to a single high-performance engine, ClickHouse joins batch financial aggregates from the Lakehouse with live delay statistics from the streaming event ledger:

ClickHouse SQL — delivery.v_transportation_cost_performance 
CREATE VIEW IF NOT EXISTS delivery.v_transportation_cost_performance AS
SELECT
    k.business_date,
    k.warehouse_id,
    k.region,
    k.route_id,
    k.cost_record_count,
    k.total_deliveries,
    k.planned_cost,
    k.actual_cost,
    k.cost_variance,
    k.cost_variance_pct,
    k.fuel_cost,
    k.driver_cost,
    k.toll_cost,
    k.maintenance_cost,
    k.other_cost,
    k.total_distance_km,
    k.cost_per_km,
    k.cost_per_delivery,
    k.fuel_cost_pct,
    k.avg_vehicle_utilization_pct,
    k.avg_delivery_duration_minutes,
    k.avg_duration_variance_minutes,
    coalesce(d.operational_delivery_count, 0) AS operational_delivery_count,
    coalesce(d.delayed_delivery_count, 0) AS delayed_delivery_count,
    coalesce(d.avg_delay_minutes, 0) AS avg_delay_minutes,
    coalesce(d.delay_rate, 0) AS delay_rate,
    k.cost_variance_pct + coalesce(d.delay_rate, 0) AS cost_delay_risk_score,
    k.published_at,
    k.version
FROM delivery.daily_transportation_cost_kpi FINAL AS k
LEFT JOIN
(
    SELECT
        toDate(event_timestamp) AS business_date,
        warehouse_id,
        region,
        route_id,
        uniqExact(delivery_id) AS operational_delivery_count,
        sum(delay_minutes > 0) AS delayed_delivery_count,
        avg(delay_minutes) AS avg_delay_minutes,
        sum(delay_minutes > 0) / greatest(count(), 1) AS delay_rate
    FROM delivery.delivery_events
    GROUP BY business_date, warehouse_id, region, route_id
) AS d
ON k.business_date = d.business_date
    AND k.warehouse_id = d.warehouse_id
    AND k.region = d.region
    AND k.route_id = d.route_id;

Dashboard 6: Transportation Cost & Route Performance

The analytical output is visualized in Apache Superset via 7 production charts and 4 native multi-select filter bars:

Chart Title Visualization Type Key Metrics / Dimensions Analytical Purpose
Total Transportation Cost Big Number SUM(actual_cost), cost_variance_pct Headline metric of actual expenditure vs. planned budget.
Cost Variance by Route Bar Chart route_id, cost_variance Ranks corridor cost deviations from budget in absolute dollars.
Cost Breakdown by Category Pie / Donut Chart Fuel, Driver, Tolls, Maintenance, Other Displays expense share distribution across cost components.
Unit Cost Trends Time-Series Line Chart business_date, cost_per_km, cost_per_delivery Tracks long-term unit cost efficiency trajectory.
Warehouse Cost Comparison Stacked Bar Chart warehouse_id, Cost Components Compares operating expenditure across distribution centers.
Cost vs. Delay Risk Scatter Scatter Plot cost_variance_pct (X) vs delay_rate (Y) Pinpoints high-risk routes suffering both overruns and delays.
Route Performance Summary Data Table Route, Planned, Actual, Variance %, $/km, Drops, Duration Full drill-down matrix for logistics managers.

Native Dashboard Filters

  • Date Range: Filters accounting business_date (Default: Last 30 days).
  • Region: Multi-select geographic region (e.g. Absheron, Baku-North).
  • Warehouse: Multi-select originating fulfillment center (e.g. WH-001).
  • Route: Multi-select logistics corridor (e.g. RT-BAKU-SUMQAYIT).

Operator Execution Runbook

Execute the complete transportation cost batch flow locally:

bash — Transportation Cost Batch Runbook
# 1. Seed synthetic route cost records into PostgreSQL (public.transportation_costs)
make seed-batch-source
# 2. Execute Spark ETL across Bronze, Silver, Gold and publish to ClickHouse
make run-batch DATASET=transportation-costs
# 3. Import or refresh Superset dashboard assets and native filters
make import-superset-assets
# 4. Verify batch transformations and schema assertions with pytest
make test-batch
