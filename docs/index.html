Dual-Application Streaming Model

To prepare for enterprise scalability (300–500 datasets), DeliveryFlow operates two distinct streaming applications side by side:

  • Application 1 (Delivery Operations — Default): Consumes from delivery-events, runs Java Flink DataStream API, and updates delivery.* operational state in ClickHouse.
  • Application 2 (Fleet Telemetry — APP=fleet): Consumes from vehicle-telemetry-events, runs Java Flink SQL/Table API, and writes telemetry, health alerts, and 5-minute rolling metrics to fleet.*.

Quick-Start Commands

Bring up the entire platform and run an end-to-end streaming and batch demonstration with these core commands:

PowerShell — Platform Bootstrap & End-to-End Demo 
# 1. Environment and configuration validation
Copy-Item .env.example .env
make config

# 2. Build and start all 10 services
make up
make health

# 3. Submit real-time streaming pipeline and publish test events
make submit-flink-job
make produce

# 4. Trigger Spark Lakehouse batch KPI job and import Superset BI assets
make spark-daily-kpi
make import-superset-assets

# 5. Display all service ports and UI endpoints
make console
