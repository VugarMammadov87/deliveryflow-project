Implemented Status

One local platform for streaming, batch, serving, and BI workflows.

DeliveryFlow runs a Docker Compose based data platform with Kafka, Flink, ClickHouse, Spark, Iceberg, Nessie, MinIO, Airflow, PostgreSQL, and Superset. Delivery is the default workflow; Fleet is selected explicitly with APP=fleet.

Implemented Delivery stream and BI

Producer, Kafka, Flink, ClickHouse, Spark KPI, and Superset assets.

Implemented Fleet telemetry serving

Fleet producer, Kafka topic, Flink SQL resource, and fleet.* tables.

Partial Central connection config

Python, scripts, and Flink have shared config; one Airflow readiness check still needs cleanup.

Operations

Common Commands

make config
make up
make submit-flink-job APP=fleet
make produce APP=fleet
make import-superset-assets
make test-e2e APP=fleet

Cleanup commands are intentionally separated. Ordinary cleanup should preserve named volumes and images; destructive cleanup requires explicit operator intent.
